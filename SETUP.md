# Belote Royale 2026 — Installation locale

## Prérequis
- Node.js 18+ (https://nodejs.org)
- pnpm (npm install -g pnpm)

## Installation

```bash
# 1. Extraire le zip et ouvrir le dossier
cd belote-royale

# 2. Installer les dépendances
pnpm install

# 3. Lancer le serveur de développement
pnpm dev
```

## Accéder au jeu
Ouvre ton navigateur sur : **http://localhost:13000**

## Fonctionnalités
- Belote Simple et Contrée
- IA experte avec mémoire des cartes
- Chat en temps réel entre joueurs
- Effets sonores
- Mode Solo contre 3 IA
- Mode Tutoriel interactif
- Reconnexion par pseudo
- Annonces avancées (tierce, quinte, carré)
- Design ultra-premium futuriste

## Jouer en multijoueur local
Ouvre plusieurs onglets sur localhost:13000, crée un pseudo différent dans chaque onglet, crée un salon puis rejoins-le depuis les autres onglets.
